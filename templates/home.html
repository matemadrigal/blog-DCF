Modelo Financiero Matemático

Fórmula DCF Core

Present Value:

PV = Σ(FCFt / (1 + r)(t - 0.5)) + TV / (1 + r)(n - 0.5)

Terminal Value (Gordon Growth):

TV = FCFn × (1 + g) / (r - g)

WACC (Weighted Average Cost of Capital):

WACC = (E/V) × Re + (D/V) × Rd × (1 - Tc)

CAPM (Cost of Equity):

Re = Rf + β × (Rm - Rf)

Equity Value:

Equity Value = Enterprise Value + Cash - Debt

Características Técnicas:
  • ✓ Mid-year discounting convention (estándar industria)
  • ✓ Validación de spread (r - g) > 2% para evitar valuaciones explosivas
  • ✓ Tasas de crecimiento escalonadas basadas en volatilidad histórica
  • ✓ Beta ajustado por Blume y Hamada (des/reapalancamiento)
  • ✓ Country Risk Premium para mercados emergentes
  • ✓ Manejo de FCF negativo en terminal value
